3. **Automate repetitive work** — Identify manual steps in a workflow and discuss which ones software could take over.

4. **Systems sit apart** — Information lives in separate applications, and you need those systems to work with one another.
5. **Software needs attention** — An existing application needs repairs, new capabilities, or a clearer path toward modernization and maintenance.
6. **The problem needs defining** — Something is getting in the way, and you need help working out the software requirement.

### Set C: visitor intentions

1. **Launch a product** — Discuss a web application, mobile app, or first product version built around a defined user need.

3. **Reduce manual steps** — Look at a repeated process and identify opportunities for software to handle the routine work.

5. **Modernize an application** — Discuss what your existing software needs to support current requirements and where changes should begin.
